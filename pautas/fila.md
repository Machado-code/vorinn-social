### Roteiros (frases na tela; palavra-chave entre asteriscos)
- **Reel 3, Escala:** "Quem trabalha no *sábado*?" → cartucho 1 cai → "Monte a *escala* do
  evento" → tela real do aviso → "a equipe vê no *sino*" → "e recebe por *e-mail*" → fecho.
- **Reel 4, Confirmação:** "Quem já *confirmou*?" → cartucho 2 cai → "cada um confirma
  pelo *portal*" → tela real → "e você vê no *painel*" (destaque em "Confirmado" e
  "Aguardando confirmação") → fecho.
- **Reel 5, Check-in:** "Quem já *chegou*?" → cartucho 3 cai → "check-in pelo *portal*" →
  "com data e *hora* registradas" → painel com "Check-in feito" → fecho.
- **Reel 6, Despesas:** "E o *estacionamento*?" → cartucho 4 cai → "a equipe lança a
  *despesa*" → tela real → "você vê quem, o quê, quanto e a *data*" → fecho.

Conferir cada frase com "O que os textos podem e não podem dizer" do `PROJETO.md`
(sem "tempo real", sem GPS ou prova de presença, despesa sem comprovante nem aprovação).
